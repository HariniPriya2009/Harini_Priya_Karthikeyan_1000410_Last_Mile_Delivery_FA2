# LogiSight Analytics
### Last Mile Delivery Intelligence Dashboard

*An interactive data analytics dashboard for understanding last-mile delivery performance, identifying delays, and improving logistics operations.*

 **Live Application:** [Open LogiSight Analytics](https://harini-priya-karthikeyan-1000410-last-mile-delivery-fa2.streamlit.app/)

---

##  Project Overview

LogiSight Analytics is an interactive dashboard developed to analyze last-mile delivery operations using data visualization and statistical analysis. It helps users explore delivery performance across different weather conditions, traffic levels, vehicle types, delivery agents, geographical areas, and time periods.

The application transforms delivery data into meaningful visual insights that can support better operational planning and data-driven decision-making.

##  Project Objectives

- Analyze average delivery time and overall delivery performance.
- Identify weather and traffic conditions associated with delivery delays.
- Compare delivery performance across different vehicle types.
- Explore relationships between agent ratings and delivery times.
- Identify geographical areas with higher average delivery times.
- Analyze delivery patterns and monthly trends.
- Provide interactive filters and downloadable reports.

##  Key Features

### 1. Interactive Dashboard
- Summary cards displaying key performance indicators (KPIs).
- Total deliveries, average delivery time, late delivery percentage, and average agent rating.
- Fastest vehicle and best-performing area indicators.
- A clean interface with a blue, purple, cyan, pink, and pastel background theme.

### 2. Delivery Delay Analysis
- Compares average delivery times under different weather and traffic conditions.
- Helps identify conditions associated with longer delivery times.
- Displays automatically generated analytical insights.

### 3. Vehicle Performance Comparison
- Compares average delivery time across vehicle categories.
- Highlights the fastest-performing vehicle category.
- Supports comparisons for operational planning.

### 4. Agent Performance Analysis
- Examines the relationship between agent ratings and delivery time.
- Groups agents by age categories.
- Includes a scatter plot and an ordinary least squares (OLS) trendline.

### 5. Geographical Heatmap
- Visualizes average delivery times across geographical areas and weather conditions.
- Highlights potential delivery bottlenecks.
- Supports comparisons between urban, semi-urban, metropolitan, and other areas.

### 6. Additional Analytics
- Category-based delivery visualizations.
- Monthly delivery trend analysis.
- Performance comparisons across different delivery conditions.
- Interactive charts that respond to the selected filters.

### 7. Dynamic Filters
Users can filter the dataset using available options such as:
- Weather conditions
- Traffic conditions
- Vehicle type
- Geographical area
- Delivery date and other available attributes

### 8. Export and Reporting
- Download filtered data as a CSV file.
- Generate a PDF report.
- Export a dashboard snapshot.
- Preview filtered dataset records within the application.

##  Key Performance Indicators

| KPI | Purpose |
|---|---|
| Total Deliveries | Measures the number of delivery records included in the analysis. |
| Average Delivery Time | Shows the average time taken to complete deliveries. |
| Late Delivery Percentage | Indicates the proportion of deliveries classified as late. |
| Average Agent Rating | Summarizes delivery agent ratings. |
| Fastest Vehicle | Identifies the vehicle category with the lowest average delivery time. |
| Best-Performing Area | Identifies the area with the best delivery performance based on the selected metric. |



##  Technologies Used

- **Python** – Data processing and application logic.
- **Streamlit** – Interactive web application and dashboard interface.
- **Pandas** – Data manipulation and analysis.

##  Analytical Approach

The dashboard follows a data analysis workflow:

1. **Data Preparation:** Load and prepare the delivery dataset for analysis.
2. **Data Processing:** Organize relevant delivery, agent, vehicle, weather, traffic, and geographical attributes.
3. **Exploratory Data Analysis:** Examine distributions, averages, relationships, and trends.
4. **Visualization:** Present patterns through KPI cards, bar charts, scatter plots, heatmaps, and trend charts.
5. **Insight Generation:** Identify patterns associated with delivery delays and operational performance.
6. **Interactive Exploration:** Allow users to change filters and investigate specific subsets of the data.
7. **Reporting:** Export filtered datasets and reports for further review.

## Expected Outcomes

The dashboard is designed to help users:

- Understand major factors associated with delivery delays.
- Compare vehicle categories using delivery-time metrics.
- Explore geographical differences in delivery performance.
- Examine delivery agent performance patterns.
- Identify areas that may require further investigation.
- Make more informed, data-driven logistics decisions.

The dashboard identifies associations and patterns in the data; these should not automatically be interpreted as proof of causation.
